## 🧬 BIKE SPEC (REFERENCE)
- Groupset: Shimano Claris R2000 (2x8)
- Drivetrain: 8-speed
- Crank: 50/34 compact (Hollowtech II)
- Bottom Bracket: BSA threaded (68mm)
- Brakes: Rim brake
- Wheel size: 700c

---

# 🔁 1. DRIVETRAIN (FULL REPLACEMENT)

## Required
- [ ] Shimano CS-HG50-8 Cassette (11-32 or 11-28)
- [ ] Shimano CN-HG71 Chain (8-speed)
- [ ] Chain quick links (x2 recommended)

## Optional (depending on wear)
- [ ] Chainrings (50/34, BCD 110mm)
- [ ] Full crankset (Shimano FC-R2000)
- [ ] Front derailleur (FD-R2000)
- [ ] Rear derailleur (RD-R2000)

## Small components
- [ ] Derailleur hanger (spare recommended)
- [ ] Jockey wheels (pulley set for 8-speed)

---

# ⚙️ 2. BOTTOM BRACKET + CRANK AREA

## Replace
- [ ] Shimano BB-RS500 Bottom Bracket (BSA 68mm)

## Service / inspect
- [ ] Crank bolts (replace if worn)
- [ ] Spacers (BB + crank)
- [ ] Dust caps

## Consumables
- [ ] Assembly grease
- [ ] Thread grease (for BB threads)

---

# 🧵 3. CABLE SYSTEM (FULL RESET — MUST DO)

## Shift system
- [ ] 2x shift inner cables (stainless or coated)
- [ ] Shift housing (full length, compressionless)

## Brake system
- [ ] 2x brake cables
- [ ] Brake housing

## Small parts (DO NOT FORGET)
- [ ] Ferrules (cable ends)
- [ ] Cable end caps (crimps)
- [ ] Frame cable stops (if damaged)
- [ ] Inline barrel adjusters (optional upgrade)

---

# 🛑 4. BRAKING SYSTEM

## Replace
- [ ] Brake pads (Shimano R55C4 or equivalent)

## Inspect
- [ ] Brake calipers (pivot smoothness)
- [ ] Springs + centering

## Optional
- [ ] Full brake calipers (if worn or weak)

---

# 🛞 5. WHEELS & TIRES

## Replace
- [ ] Tires (700x28 recommended)
- [ ] Inner tubes (x2 + spare)
- [ ] Rim tape (correct width for rims)

## Inspect
- [ ] Rims (brake surface wear)
- [ ] Spokes (tension + damage)
- [ ] Hubs (bearing smoothness)

## Optional
- [ ] Tubeless valves (if converting)
- [ ] Sealant (if tubeless)

---

# ⚙️ 6. BEARINGS (FULL BIKE)

## Replace or service
- [ ] Bottom bracket (already listed)
- [ ] Headset bearings (upper + lower)
- [ ] Wheel hub bearings (front + rear)
- [ ] Pedal bearings (or pedals)

## Consumables
- [ ] Bearing grease
- [ ] Anti-seize compound

---

# 🪑 7. COCKPIT & CONTACT POINTS

## Replace
- [ ] Bar tape
- [ ] Bar end plugs

## Service
- [ ] Stem bolts
- [ ] Seatpost clamp

## Optional
- [ ] Saddle
- [ ] Seatpost (if worn or damaged)

## Consumables
- [ ] Carbon paste (if carbon parts)
- [ ] Assembly grease

---

# 🔩 8. FRAME & HARDWARE

## Replace / check
- [ ] Bottle cage bolts
- [ ] Derailleur hanger bolts
- [ ] Brake mounting bolts
- [ ] Cable guides under BB

## Inspect
- [ ] Frame (cracks, especially welds)
- [ ] Dropouts alignment

---

# 🧼 9. CLEANING & LUBRICATION

## Mandatory
- [ ] Degreaser
- [ ] Chain lubricant (wet or dry)
- [ ] Isopropyl alcohol (final cleaning)

## Optional
- [ ] Bike polish / frame protection spray

---

# 🔧 10. TOOLS (ESSENTIAL FOR FULL REBUILD)

## Drivetrain tools
- [ ] Cassette lockring tool
- [ ] Chain whip
- [ ] Chain breaker tool

## Bottom bracket
- [ ] Hollowtech II BB tool

## General
- [ ] Torque wrench (VERY recommended)
- [ ] Hex key set (Allen keys)
- [ ] Cable cutter (sharp, bike-specific)
- [ ] Screwdrivers

## Advanced (optional but pro)
- [ ] Bearing press / puller
- [ ] Derailleur hanger alignment tool
- [ ] Work stand

---

# ⚠️ 11. CRITICAL COMPATIBILITY NOTES

- ONLY use **8-speed drivetrain components**
- Bottom bracket MUST be **BSA 68mm threaded**
- Crank = **Hollowtech II compatible**
- Chain MUST match cassette (8-speed)
- Rim brake pads must match rim type (alloy)

---

# 🚀 12. BUILD ORDER (CLEAN WORKFLOW)

1. Strip bike → bare frame
2. Deep clean everything
3. Install:
   - Headset + fork
   - Bottom bracket + crank
4. Install wheels
5. Install drivetrain (cassette → chain → derailleurs)
6. Install cables (shift + brake)
7. Install brakes
8. Wrap bar tape
9. Tune:
   - Index gears
   - Brake alignment
10. Final torque check

---

# 🧠 13. MOST FORGOTTEN ITEMS (CHECK TWICE)

- [ ] Rim tape
- [ ] Cable housing (not just cables)
- [ ] Ferrules + end caps
- [ ] Jockey wheels
- [ ] Grease everywhere metal meets metal
- [ ] Correct BB standard (BSA vs pressfit)

---

# 🧩 14. OPTIONAL UPGRADES (WHILE YOU’RE THERE)

- [ ] Better tires (biggest performance gain)
- [ ] Compressionless cable housing
- [ ] New saddle
- [ ] Pedals upgrade
- [ ] Ceramic BB (if you want overkill)
